# meus-projetos-python

Projetos e exercícios em Python desenvolvidos durante meus estudos.

Aqui você vai encontrar desde scripts simples de lógica até pequenos jogos e testes de personalidade — sempre com uma pitada de humor, porque aprender programando não precisa ser chato.

## 📁 Projetos

### `funcao.py`
Exercício de estudo sobre funções em Python. Cumprimenta 50 nomes diferentes sem repetição — um jeito simples de praticar laços de repetição, listas e lógica de função.

### `jogo_de_adivinha.py`
Jogo clássico de adivinhação: o programa escolhe um número (ou palavra) e o usuário tenta acertar com dicas ao longo das tentativas.

### `perguntas.py`
Quiz de sim ou não — cada resposta leva a um resultado diferente. Simples, direto e com umas respostas bem-humoradas no final.

### `sentimentos.py`
Um teste de "personalidade" com 3 perguntas e 3 alternativas cada. Cada combinação de resposta leva a um resultado diferente. Feito pra ser divertido, não é ciência exata (nem tenta ser).

### `teste.py`
Script de testes e experimentações — onde tento coisas novas antes de "oficializar" em outro arquivo.

## 🛠️ Tecnologias

# my-python-projects

Python projects and exercises built while I study programming.

Here you'll find everything from simple logic scripts to small games and personality quizzes — always with a bit of humor, because learning to code doesn't have to be boring.

## 📁 Projects

### `funcao.py`
A study exercise on Python functions. Greets 50 different names without repetition — a simple way to practice loops, lists, and function logic.

### `jogo_de_adivinha.py`
A classic guessing game: the program picks a number (or word) and the user tries to guess it, with hints along the way.

### `perguntas.py`
A yes-or-no quiz — each answer leads to a different outcome. Simple, straightforward, and with some funny results at the end.

### `sentimentos.py`
A "personality test" with 3 questions and 3 options each. Every combination of answers leads to a different result. Meant to be fun, not scientifically accurate (and it doesn't try to be).

### `teste.py`
A scratchpad file for testing and experimenting — where I try new things before "officializing" them into another file.

## 🛠️ Tech Stack
- Python 3

## 🚀 How to run
```bash
python file_name.py
```
